# 領先潛力族群 Dashboard

- **頁面**：Alan 台股儀表板 → 領先潛力族群
- **網址**：<http://140.112.174.201:8052/leading-sector>
- **檔案**：`alan_dashboard/pages/leading_sector.py`
- **範圍**：上市 + 上櫃（TSE + OTC）全市場

依六項條件篩選個股，以證交所產業分類呈現「族群家數分布」，並可選擇日期瀏覽歷史。

## 篩選條件

條件 1、4、5、6 須同時成立（AND），條件 2 與 3 擇一成立即可（OR）。
價格計算一律使用**還原價格**（`etl:adj_close` / `etl:adj_high` / `etl:adj_low`），與 Alan 系列策略一致。

| # | 條件 | 計算方式 |
| --- | --- | --- |
| 1 | 收盤價大於 480 天新高 90% | 還原收盤 ≥ 近 **480** 交易日**盤中最高價**（還原）× **90%**（非收盤新高） |
| 2 | 營益率增 12% + 買超排行前 40 檔 | 本季營益率 > 前季 × **1.12**，且買超排行進前 **40** |
| 3 | 營益率增 0.1% + 買超排行前 20 檔 | 本季營益率 > 前季 × **1.001**，且買超排行進前 **20** |
| 4 | 60 日均線乖離小於 28% | （還原收盤 − MA60）÷ MA60 < **28%** |
| 5 | 120 日均線乖離小於 45% | （還原收盤 − MA120）÷ MA120 < **45%** |
| 6 | 收盤價小於近 15 天最低價的 132% | 還原收盤 ÷ 近 **15** 交易日最低還原價 ≤ **1.32** |

### 買超排行（籌碼面，與 `strategy_class/alan_tw_strategy_base.py` 一致）

以「買賣超股數 ÷ 發行股數」計算比例後，在全市場（TSE + OTC）橫向排名。
**外資 ｜ 投信 ｜ 自營商 ｜ 主力（前 15 大券商）四者擇一成立即可**。

| 來源 | 條件 |
| --- | --- |
| 外資（外陸資買賣超，不含外資自營商） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 N |
| 投信 | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 N |
| 自營商（自行買賣） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 N |
| 主力（top15 買 − top15 賣） | 排名前 N **且** 同時滿足對應比率門檻（見下表） |

主力額外的比率門檻（需與同期間排名條件同時成立）：

| 期間 | 比率門檻 |
| --- | --- |
| 1 日 | > 0.08%（0.0008） |
| 2 日累計 | > 0.15%（0.0015） |
| 3 日累計 | > 0.25%（0.0025） |

N 依條件而定：條件 2 為 40、條件 3 為 20。

### 營益率增（基本面）

季頻營業利益率（`fundamental_features:營業利益率`）與前一季比較：本季 > 前季 × 門檻，
依財報公告日對齊至日線。

## 產業分類

使用 `security_categories` 的 `category` 欄位（證交所／櫃買產業分類），名稱顯示 `name` 欄。
很早期下市的股票則可能顯示舊制粗分類（如「電子工業」）。

類股顏色使用 12 色色盤，依當日類股柱順序（家數多→少）逐一指派——
同一畫面相鄰柱必不同色，單日類股超過 12 個才會循環重複；
顏色不跨日期固定，類股身分以圖表下方的類股標籤為準。

## 儀表板功能

- **族群家數分布圖**：橫軸為類股（依家數多→少排序），每檔個股一個色塊，
  滑鼠停留顯示收盤價、乖離率、符合條件與買超來源。圖表鎖定不可縮放。
- **入選個股明細表**：代號、名稱、類股、收盤價（未還原，當日實際收盤價）、
  收盤/480日高、60/120 日乖離、收盤/15日低、符合條件（2 或 3）、買超來源，可點欄位排序。
  條件與各比率皆以還原價計算。
- **訊號日卡片**：顯示的日期為收盤資料日，訊號供下一交易日操作參考。
- **日期選擇 + ‹ › 按鈕**：瀏覽歷史分布，範圍為最新交易日往前一年；
  選到非交易日（週末、國定假日、颱風停市等）自動貼齊前一個交易日。

## 資料更新機制

- 篩選結果於伺服器啟動時計算一次並快取於記憶體，開頁直接顯示快取，不需等待。
- 伺服器每天 **21:45**（台北時間）自動重新拉取 FinLab 資料並重算，過程中其他使用者不受影響：
  21:45 前看到的是前一交易日的收盤資料，21:45 後才會出現當日資料。
  固定時間而非一有新資料就更新，是因為 FinLab 各資料集陸續更新（價格先到、法人與分點稍晚），
  避免出現「價格是今天、籌碼還是昨天」導致當日名單短少的中間狀態。
- 已開著的網頁不會自己重畫，21:45 後重新載入頁面即可。
- 沒有手動更新按鈕。若 22:00 後「資料更新」時間仍不是當天 21:45 以後，代表當天自動重算失敗
  （不重試，隔天 21:45 會再算）；急用時請通知維運重啟服務（啟動時會重算一次）。

## 判讀邏輯

本頁選出的是「瀕臨創 480 天新高」（距離長期新高 10% 以內）的股票，即**領先股候選名單**——
尚未真正突破，也可能始終不發動。定位是**觀察雷達**：用名單的變化判斷行情位置，而非買賣訊號。

### 領先股、主流股、補漲股

三者是依時間順序出場的角色：

```
行情低檔 ──────── 中段 ──────── 高檔 ── 結束
   │                │              │
 領先股先出現      類股輪漲      補漲股才漲
   │                              （如金融股）
   └─ 其中一部分 ──→ 成為主流股，從頭漲到尾
```

- **領先股**：大盤還在跌或剛穩定時，率先瀕臨創長期新高的股票。
  領先股容易成為主流股，但不一定（歐尼爾概念）。
- **主流股**：整波行情漲最多、貫穿全場的族群，通常從領先股中誕生。
- **補漲股**：整波都沒漲、行情尾聲才輪動補漲的股票（金融股為典型）。
  與領先股是不同族群；補漲股開始漲即為行情將盡的警訊。

### 依行情位置判讀名單

| 行情位置 | 觀察重點 | 意義 |
| --- | --- | --- |
| 低檔 | 大盤還在跌或剛穩定時**新進榜**的股票 | 真正的領先股，最可能成為主流，確定性最高的買進候選 |
| 中段 | 新進榜多為類股輪漲；觀察族群遷移（如記憶體 → 其他） | 確定性較弱 |
| 高檔 | 入選**家數萎縮**（幾十檔 → 越來越少） | 原本在漲的股票陸續下跌、市場廣度惡化；此階段訊號容易失敗 |

其他原則：

- 重點看**新進榜**的股票；久掛不動的舊面孔不需特別關注——
  真的漲上去會因乖離擴大被剔除而消失，一直留在名單上代表沒漲。
- 篩選器幾乎選不出股票 → 行情不佳。

### 與領先潛力族群策略的分工

核心架構相同（六條件、LS40/LS20 籌碼＋基本面配對、480 天 × 90%、收盤/15 日低 ≤ 1.32），定位互補：

| | 儀表板（本頁） | 策略（`AlanTWStrategyLeadingSector`，見 `docs/alan_tw_strategy_leading_sector.md`） |
| --- | --- | --- |
| 定位 | 觀察雷達：判斷行情位置 | 交易系統：決定買賣點，可回測 |
| 發動條件 | 無——瀕臨新高即上榜，不論量能 | 有——量能翻倍、DMI、KD 雙升、DIF 上升，等爆量發動才進場 |
| 乖離上限 | 60 日 < 28%、120 日 < 45% | 60 日 < 24%、120 日 < 34%（較嚴） |
| 流動性門檻 | 無 | 500 張、12 元、3,000 萬成交額 |
| 出場 | 無 | simple 出場＋急殺出場 |

儀表板列出候選名單供判斷大盤階段；策略在候選人中等某檔真正爆量發動才買進——
不發動的股票儀表板看得到，策略不會買。

## 實作備註

- 訊號索引鎖定為「當日有還原收盤價資料」的實際交易日，
  避免事件型資料（發行股數）將非交易日帶入索引。
- 計算起點為可瀏覽起點再往前 800 日曆日，以涵蓋 480 交易日 rolling 視窗的暖身期。
- 快取與每日更新的實作見 `alan_dashboard/cache.py`；
  callback 一律先取快取快照再讀取，避免與背景重算混用新舊資料。
