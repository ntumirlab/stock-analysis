# EFG 未發動模型

- **類別**：`AlanTWStrategyEFGNotStart`
- **檔案**：`strategy_class/alan_tw_strategy_efg_not_start.py`
- **基底**：`AlanTWStrategyNotStartBase`
- **子策略**：E｜F｜G，各自獨立進出場，持倉取聯集

## 進場條件

三大類條件必須**同時成立**：籌碼面 AND 技術面 AND 基本面。

### 籌碼面

以「買賣超股數 ÷ 發行股數」的比例計算，並取當日全市場排名。三組條件**任一成立**即可：

| 來源 | 條件 |
| --- | --- |
| 外陸資（不含外資自營商） | 1 日、2 日累計、3 日累計買超比例，任一項排名進入全市場前 `top_n` |
| 自營商（自行買賣） | 同上，1／2／3 日任一項排名進入前 `top_n` |
| 主力（前 15 大券商買超 − 賣超） | 排名進入前 `top_n` **且**買超比例超過門檻，1／2／3 日任一組成立 |

主力籌碼的比例門檻：

| 期間 | 買超比例門檻 |
| --- | --- |
| 1 日 | > 0.08% |
| 2 日累計 | > 0.15% |
| 3 日累計 | > 0.25% |

三個子策略的 `top_n` 均為 **40**（程式中會檢查三者一致，籌碼面只計算一次共用）。

> 註：程式中亦計算了投信買賣超條件，但未納入最終的籌碼面聯集判斷。

### 基本面

| 條件 | 說明 |
| --- | --- |
| 營業利益率成長 | 本期營業利益率 > 前期營業利益率 × `op_growth` |

三個子策略的 `op_growth` 均為 **1.12**（即季增 12% 以上），同樣只計算一次共用。

### 技術面

**沒有**下列發動型條件：量能翻倍、均線上升、價格站上均線、KD 向上、MACD DIF 向上、創新高。

實際要求的條件如下，全部必須同時成立：

| 條件 | 門檻 |
| --- | --- |
| 六組乖離率 | 5／10／20／60／120／240 日乖離皆落在該子策略的區間內（見下表） |
| 股價 | 收盤價 > 12 元 |
| 成交量 | 成交股數 > 300 張（300,000 股） |
| 成交金額 | 收盤價 × 成交股數 > 1,500 萬元 |
| 貼近新高 | 還原收盤價 >= 近 N 日還原收盤最高價 × `entry_high_pct` |
| DMI（+DI） | +DI(14) > **22** |
| DMI（−DI） | −DI(14) < **24** |

DMI 門檻由類別屬性 `entry_plus_di_min = 22`、`entry_minus_di_max = 24` 指定（基底預設為 `None`，即不使用 DMI）。

## 出場條件

每個子策略**用自己的 `new_high_days`、`exit_high_pct` 與自己的 bias_20／bias_60 上限**計算出場訊號，與該子策略的買訊配對成獨立持倉。

下列任一條件成立即出場：

| # | 條件 | 意義 |
| --- | --- | --- |
| 1 | 5 日乖離 < −4% | 短線跌破 |
| 2 | 10 日乖離 < −4% | 短線跌破 |
| 3 | 還原收盤價 < 近 N 日還原收盤最高價 × `exit_high_pct`（0.91） | 跌離長期高檔區 |
| 4 | 20 日乖離 > 該子策略 bias_20 進場上限 | 漲過頭，已非「未發動」 |
| 5 | 60 日乖離 > 該子策略 bias_60 進場上限 | 漲過頭，已非「未發動」 |

條件 4、5 是這個模型特有的：股價一旦大幅噴出、乖離超過進場區間上限，就視為「已發動」而離場。

## 回測設定

| 項目 | 設定 |
| --- | --- |
| 回測起始日 | 2017-12-31 |
| 單檔持股上限 | **無上限**（`position_limit = None`） |
| 手續費 | 0.1425%（`fee_ratio = 0.001425`） |
| 交易稅 | 0.3%（`tax_ratio = 0.003`） |
| 滑價 | 0%（`slippage = 0.0`） |
| 成交價 | 以還原股價前一日收盤計（`AdjustTWMarketInfo`） |
| 再平衡頻率 | 不重取樣（`resample=None`），依訊號逐日進出 |

> 未發動模型不設單檔上限，且價量門檻較低（成交量 300 張、成交金額 1500 萬），
> 係模型定位所致 —— 追蹤的是尚未發動、成交量相對清淡的候選股。
