# EFG 95% 新高 完整出場

- **類別**：`AlanTWStrategyEFG95Full`
- **檔案**：`strategy_class/alan_tw_strategy_efg95_full.py`
- **子策略**：E、F、G，買入訊號取三者聯集

## 進場條件

買入訊號 = 籌碼面 AND 基本面 AND 技術面（三大類全部成立）。

### 籌碼面

以「買賣超股數 ÷ 發行股數」計算比例後，在全市場（TSE + OTC）橫向排名。
**外資 ｜ 自營商 ｜ 主力（前 15 大券商）三者擇一成立即可**，投信不計入。

| 來源 | 條件 |
| --- | --- |
| 外資（外陸資買賣超，不含外資自營商） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 `top_n` |
| 自營商（自行買賣） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 `top_n` |
| 主力（top15 買 − top15 賣） | 排名前 `top_n` **且** 同時滿足對應比率門檻（見下表） |
| 投信 | **不列入**買進條件 |

主力額外的比率門檻（需與同期間排名條件同時成立）：

| 期間 | 比率門檻 |
| --- | --- |
| 1 日 | > 0.08%（0.0008） |
| 2 日累計 | > 0.15%（0.0015） |
| 3 日累計 | > 0.25%（0.0025） |

本策略三個子策略的 `top_n` 皆為 **40**。

### 基本面

| 條件 | 門檻 |
| --- | --- |
| 營業利益率 QoQ 成長 | 本季營益率 > 前季營益率 × **1.12**（即成長 **12%** 以上） |

### 技術面

| 項目 | 條件 |
| --- | --- |
| 均線上升 | MA5、MA10、MA20、MA60 皆較前一日上升 |
| 價格站上均線 | 收盤價同時 > MA5、MA10、MA20、MA60 |
| 乖離率 | 5/10/20/60/120/240 日乖離率**全部**落在各子策略設定區間內 |
| 量能翻倍 | 成交股數 > 前一日成交股數 × 2 |
| 成交量下限 | 成交股數 > 500,000 股（500 張） |
| 股價下限 | 收盤價 > 12 元 |
| 成交金額 | 收盤價 × 成交股數 > 30,000,000（3,000 萬元） |
| DMI（14 日） | **+DI > 24** 且 **−DI < 21** |
| KD（台股式，fastk 9、alpha 1/3） | K 較前一日上升 **且** D 較前一日上升 |
| MACD（12, 26, 9） | DIF 較前一日上升 |
| 創新高 | 收盤價 ≥ N 日收盤最高價 × **95%**（N 依子策略而定） |

## 出場條件

`sell_type = 'full'`

```
3日線下彎 AND DIF 下彎 AND (
      -DI > 21
   OR (3日乖離 < -3.5% AND 5日乖離 < -3.5%)
   OR (DEA 下彎 AND 3日乖離 < -2.5% AND 5日乖離 < -2.5%)
   OR (ADX > 31 AND 3日乖離 < -0.5% AND 5日乖離 < -0.5%)
)
```

| 部分 | 判定 |
| --- | --- |
| 前提（必要條件） | MA3 < 前一日 MA3 **且** DIF < 前一日 DIF |
| 觸發 1：趨勢轉弱 | −DI（14 日）> 21 |
| 觸發 2：深度跌破 | 3 日乖離與 5 日乖離皆 < −0.035 |
| 觸發 3：MACD 訊號線下彎 | DEA < 前一日 DEA，且 3 日與 5 日乖離皆 < −0.025 |
| 觸發 4：強趨勢中轉弱 | ADX（14 日）> 31，且 3 日與 5 日乖離皆 < −0.005 |

前提成立後，四個觸發條件**任一**成立即出場。
