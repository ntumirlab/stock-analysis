## 模型邏輯

以均線條件式 **S4 分數**（範圍 −10 ~ +10）衡量大盤多空，
由「均線分數 + DMI 分數」為主體，再依動能指標（MACD、KD）微調，最後加上現貨分數。
評分邏輯在 `alan_dashboard/market_regime_model.py`。

### 資料來源

TAIEX 開／高／低／收盤指數（`taiex_total_index`），全歷史。
指標以指數本身計算：DMI／MACD 用 talib 標準算法，KD 為台股式自算（alpha = 1/3）。
現貨分數另用個股收盤價（`price:收盤價`）、市值（`etl:market_value`）與證券分類（`security_categories`）。

### 均線分數（−2 ~ +2）

以收盤指數與 MA5／MA10／MA20 的相對位置計分：

| 收盤指數位置 | 分數 |
| --- | --- |
| 站上 MA5、MA10、MA20 | +2 |
| 站上 MA5、MA10，未站上 MA20 | +1 |
| 未站上 MA5，站上 MA10、MA20 | +1 |
| 僅站上 MA20 | −1 |
| 三條均線皆未站上 | −2 |
| 其他組合 | 0 |

### DMI 分數（−4 ~ +4，14 日）

TAIEX 門檻：高 = **35**、中 = **21**、低 = **18**。+DI 與 −DI 分數相加：

| 條件 | +DI 計分 | −DI 計分 |
| --- | --- | --- |
| > 35 | +2 | −2 |
| 21 ~ 35 | +1 | −1 |
| 18 ~ 21 | −1 | +1 |
| < 18 | −2 | +2 |

### 動能微調（−3 ~ +3）

小計（均線 + DMI）**< 5** 時，以下每項成立各 **−1**：

- DIF 較前一日下彎
- MACD 訊號線（DEA）較前一日下彎
- K 與 D 同步下彎

小計 **> −5** 時，以下每項成立各 **+1**：

- DIF 較前一日上升
- MACD 訊號線（DEA）較前一日上升
- K 與 D 同步上升

（MACD 參數 12, 26, 9；KD 為 9 日 RSV、K/D 皆以 alpha = 1/3 平滑）

### 現貨分數（−1 ~ +1）

台灣50 + 台灣中型100 共 150 檔個股中，「5、10、20 日均線同時向上」的檔數減去
「三條均線同時向下」的檔數（向上 = 當日均線值高於前一日，與其他策略一致）：

| 檔數差 | 分數 |
| --- | --- |
| > +25 | +1 |
| −25 ~ +25 | 0 |
| < −25 | −1 |

現貨分數直接加在最後，不影響動能微調的觸發條件（小計仍只看均線 + DMI）。

**成分股來源**：FinLab 沒有台灣50／中型100 的成分股資料，改以「上市普通股市值前 150 名」
近似（排除 ETF、特別股、TDR 與創新板），每季最後一個交易日重排一次、次一交易日起生效、整季鎖定，
對應官方每季審核換股的行為。
官方指數用自由流通市值加流動性篩選、並有緩衝規則，因此名單邊緣會有些許不同：
以 2026-09-16 元大 0050 + 0051 實際持股比對，150 檔中有 8 檔不同（皆在市值排名 110 ~ 240 的邊緣），
台灣50 與中型100 之間的互換（例如遠傳在市值 53 名仍在 0050）在合併後不影響。
指標是檔數差、門檻 ±25 檔，這 8 檔的影響可忽略。

個股資料比指數晚更新時（指數已有當日、個股尚未），該日檔數差無值，現貨分數以 0 計、明細表顯示「—」。

## 訊號判定

| 分數 | 訊號 |
| --- | --- |
| > 0 | 🟢 做多 |
| −1 ~ 0 | ⚪ 觀望 |
| < −1 | 🔴 出場 |

## 儀表板功能

- **K 線 + 分數柱狀圖**：上半 TAIEX K 線（台灣慣例紅漲綠跌），下半 S4 分數柱
  （紅 = 做多、綠 = 出場、灰 = 觀望），非交易日自動隱藏。圖表鎖定不可縮放。
- **期間切換**：1M / 2M / 3M / 6M / 1Y，預設 2M。
- **分數明細表**：圖表下方列出期間內每個交易日的各條件數值與分數（最新日在前，可排序、每頁 20 筆）：
  收盤、站上哪幾條均線與均線分、+DI／−DI 數值與 DMI 分、小計、DIF／MACD／KD 的方向箭頭與實際計分
  （小計未達門檻時方向成立但計 0）、現貨檔數差與現貨分、總分、訊號。正分紅字、負分綠字。
  分數柱狀圖的 hover 也會顯示各項分數。
- **訊號日卡片**：顯示收盤資料日與資料更新時間，訊號供下一交易日操作參考。

## 資料更新機制

- 分數於伺服器啟動時計算一次並快取於記憶體，開頁直接顯示快取，不需等待。
- 伺服器每天 **21:45**（台北時間）自動重新拉取 FinLab 資料並重算：
  21:45 前看到的是前一交易日的收盤資料，21:45 後才會出現當日資料。
- 已開著的網頁不會自己重畫，21:45 後重新載入頁面即可。
- 沒有手動更新按鈕。若 22:00 後「資料更新」時間仍不是當天 21:45 以後，代表當天自動重算失敗
  （不重試，隔天 21:45 會再算）；急用時請通知維運重啟服務（啟動時會重算一次）。
