## 模型邏輯

以均線條件式 **S4 分數**（範圍 −11 ~ +11）衡量大盤多空，
由「均線分數（±1 需 KD 同向確認）+ DMI 分數」為主體，再依動能指標（MACD）微調，最後加上現貨分數與選擇權分數。
評分邏輯在 `alan_dashboard/market_regime_model.py`。

### 資料來源

TAIEX 開／高／低／收盤指數（`taiex_total_index`），全歷史。指數沒有還原價的問題。
指標以指數本身計算：DMI 用 talib；MACD 與 KD 與各策略一致，採 `strategy_class/taiwan_macd.py`
（加權收盤價 (H+L+2C)/4）與 `strategy_class/taiwan_kd.py`（alpha = 1/3）。
現貨分數另用個股還原收盤價（`etl:adj_close`）、市值（`etl:market_value`）與證券分類（`security_categories`）。
選擇權分數用台指選擇權逐契約未沖銷部位（`tw_taifex_option_liquidity`，2025-09-25 起）。

### 均線分數（−2 ~ +2）

以收盤指數與 MA5／MA10／MA20 的相對位置計分，±1 的組合另需 KD 同向確認：

| 收盤指數位置 | KD 條件 | 分數 |
| --- | --- | --- |
| 站上 MA5、MA10、MA20 | 不看 | +2 |
| 站上 MA5、MA10，未站上 MA20 | K、D 同步上升 | +1 |
| 未站上 MA5，站上 MA10、MA20 | K、D 同步上升 | +1 |
| 僅站上 MA20 | K、D 同步下降 | −1 |
| 三條均線皆未站上 | 不看 | −2 |
| 其他組合 | — | 0 |

±1 的組合若 KD 未同向（例如站上 MA5、MA10 但 K↑ D↓，或 K、D 同步下降）計 0。
KD 為 9 日 RSV、K/D 皆以 alpha = 1/3 平滑；同步上升／下降指 K 與 D 都較前一日上升／下降。
KD 不再單獨計分：改為均線 ±1 的確認條件，是為了避免 KD 每天翻向造成分數不穩定。

### DMI 分數（−4 ~ +4，14 日）

TAIEX 門檻：高 = **35**、中 = **21**、低 = **18**。+DI 與 −DI 分數相加：

| 條件 | +DI 計分 | −DI 計分 |
| --- | --- | --- |
| > 35 | +2 | −2 |
| 21 ~ 35 | +1 | −1 |
| 18 ~ 21 | −1 | +1 |
| < 18 | −2 | +2 |

### 動能微調（−2 ~ +2）

小計（均線 + DMI）**< 5** 時，以下每項成立各 **−1**：

- DIF 較前一日下彎
- MACD 訊號線（DEA）較前一日下彎

小計 **> −5** 時，以下每項成立各 **+1**：

- DIF 較前一日上升
- MACD 訊號線（DEA）較前一日上升

（MACD 參數 12, 26, 9，以加權收盤價計算）

上升／下彎的判斷含相對容忍值：變動幅度未超過 「指標值與基準值取較大者」× 1e-9 者視為持平，用來濾除浮點運算殘留的誤差。
基準值：DIF／DEA 用指數收盤、K／D 用滿刻度 100（指標接近 0 時門檻才不會消失）；現貨分數的均線方向以均線自身為基準值。
與 Alan 各策略的 `direction_tol` 規則相同。

### 現貨分數（−1 ~ +1）

台灣50 + 台灣中型100 共 150 檔個股中，「5、10、20 日均線同時向上」的檔數減去
「三條均線同時向下」的檔數（向上 = 當日均線值高於前一日，與其他策略一致；均線以還原價計算，
避免除權息造成的假跌）：

| 檔數差 | 分數 |
| --- | --- |
| > +25 | +1 |
| −25 ~ +25 | 0 |
| < −25 | −1 |

現貨分數直接加在最後，不影響動能微調的觸發條件（小計仍只看均線 + DMI）。

**成分股來源**：FinLab 沒有台灣50／中型100 的成分股資料，改依官方編製規則，
用 FinLab 市值資料模擬 150 檔合併名單：

- 母體為上市普通股（排除 ETF、特別股、TDR 與創新板），以市值（公眾流通量調整前）排名。
  官方入選也是看這個市值，公眾流通量只影響權重與資格。
- 季度審核時程與官方相同：每年 3、6、9、12 月第三個星期五收盤後生效（下一個交易日，通常是星期一），
  審核資料為生效日前四週星期一的收盤資料。台灣50 與中型100 同一天換股。
- 緩衝規則與官方相同：非成分股市值排名升到第 130 名以上才納入，成分股跌到第 171 名以下才剔除，
  再以排名遞補或削減維持 150 檔。因此排名 131 ~ 170 的股票會維持原狀，這就是為什麼市值
  第 53 名的遠傳仍在台灣50（台灣50 自己的緩衝是第 40／61 名），合併名單不受這種內部互換影響。
- 官方另有流動性檢驗（月週轉率）與非定期事件（快速納入、下市），沒有模擬。

以 2026-09-16 元大 0050 + 0051 實際持股比對，模擬名單 150 檔中只有 3 檔不同，
皆在排名 136 ~ 166 的緩衝區邊緣。指標是檔數差、門檻 ±25 檔，影響可忽略。

**資料更新時序的防呆**：FinLab 的指數資料與個股資料不是同一時間更新。若重算當下指數已有當天的 K 棒、
個股收盤價還沒有（或只有少數幾檔），當天的檔數差算不出來：此時現貨分數以 0 計、明細表該格顯示「—」，
不會被誤算成「0 檔」。每天 21:45 的自動重算兩者都已更新，正常情況不會遇到。

### 選擇權分數（−2 ~ +2）

台指選擇權（TXO）的 **未平倉量** Put/Call 比：賣權未沖銷部位 ÷ 買權未沖銷部位 × 100（%）。
大於 100% 代表持有賣權（看跌）的部位多於買權（看漲）。依到期月份分成當月與遠月：

| 項目 | 定義 |
| --- | --- |
| 當月 P/C | 最近一個尚未到期的月契約（例如 9 月契約在 9/16 到期後，當月即為 10 月契約） |
| 遠月 P/C | 當月以後所有月契約合計（含季月，例如 11 月、12 月、隔年 3 月、6 月） |

週契約（到期月份代號含 W 的週三到期、含 F 的週二到期）兩邊都不計。

| 條件 | 分數 |
| --- | --- |
| 當月 P/C > 120%，且當月 > 遠月 | +1 |
| 當月 P/C < 90% | −1 |
| 當月 P/C > 140% | 再 +1 |
| 遠月 P/C > 100%，且遠月 > 當月 | 再 −1 |

四個條件各自判斷、可累加（例如當月 150%、遠月 120%：+1 +1 = +2；當月 150%、遠月 160%：+1 −1 = 0；
當月 85%、遠月 105%：−1 −1 = −2）。
選擇權分數與現貨分數一樣直接加在最後，不影響動能微調的觸發條件。
P/C 無值的日期（資料起始 2025-09-25 之前、或當天尚未更新）選擇權分數以 0 計、明細表該格顯示「—」。

只有未平倉量版本：FinLab 沒有逐契約的當日成交量（`tw_option_daily_summary` 每天只列少數履約價，
加總與官方合計對不上），成交量版的當月／遠月 P/C 目前算不出來。

**驗證**：全部契約（含週契約）加總的 P/C 與期交所官方每日公布的合計（`tw_option_put_call_ratio`）
逐日完全一致；當月／遠月的算法以 Alan 提供的 2026-09-18 數值（當月 75%、遠月 57%）核對，
算出 75.3% 與 56.9%。`tw_taifex_option_liquidity` 的未沖銷部位口數是官方的 2 倍（買賣雙邊各計一次），
比率不受影響。

## 訊號判定

| 分數 | 訊號 |
| --- | --- |
| > 0 | 🔴 做多 |
| −1 ~ 0 | ⚪ 觀望 |
| < −1 | 🟢 出場 |

燈號顏色依台灣慣例（紅漲綠跌），與 K 線、分數柱一致。

## 儀表板功能

- **K 線 + 分數柱狀圖**：上半 TAIEX K 線（台灣慣例紅漲綠跌），下半 S4 分數柱
  （紅 = 做多、綠 = 出場、灰 = 觀望），非交易日自動隱藏。圖表鎖定不可縮放。
- **期間切換**：1M / 2M / 3M / 6M / 1Y，預設 2M。
- **分數明細表**：圖表下方列出期間內每個交易日的各條件數值與分數（最新日在前，可排序、每頁 20 筆）：
  收盤指數、站上哪幾條均線、KD 方向（K、D 同向時為單一箭頭，不同向時分別列出，如「K↑ D↓」）與均線分、
  +DI／−DI 數值與 DMI 分、小計、DIF／MACD 的方向箭頭與實際計分（小計未達門檻時方向成立但計 0）、
  現貨檔數差與現貨分、當月 P/C、遠月 P/C（一位小數）與選擇權分、總分、訊號。正分紅字、負分綠字，數值欄可依數值排序。
  +DI／−DI 與 P/C 的計分用未四捨五入的原值，顯示值剛好等於門檻（如 +DI 顯示 35.0、當月 P/C 顯示 90.0%）時，
  分數以原值為準，可能與表面數字看起來不一致。
  分數柱狀圖的 hover 也會顯示各項分數。
- **訊號日卡片**：顯示收盤資料日與資料更新時間，訊號供下一交易日操作參考。

## 資料更新機制

- 分數於伺服器啟動時計算一次並快取於記憶體，開頁直接顯示快取，不需等待。
- 伺服器每天 **21:45**（台北時間）自動重新拉取 FinLab 資料並重算：
  21:45 前看到的是前一交易日的收盤資料，21:45 後才會出現當日資料。
  選擇權未沖銷部位在 FinLab 約每天 19:20 更新當日資料，21:45 重算時已可取得。
- 已開著的網頁不會自己重畫，21:45 後重新載入頁面即可。
- 沒有手動更新按鈕。若 22:00 後「資料更新」時間仍不是當天 21:45 以後，代表當天自動重算失敗
  （不重試，隔天 21:45 會再算）；急用時請通知維運重啟服務（啟動時會重算一次）。
