# 領先潛力族群 AE 90% 簡單出場

- **類別**：`AlanTWStrategyLeadingAE90Simple`
- **檔案**：`strategy_class/alan_tw_strategy_leading_ae90_simple.py`
- **子策略**：A'、E'，買入訊號取兩者聯集
- **關聯**：籌碼面＋基本面的配對沿用「領先潛力族群」儀表板的條件 2／3
  （`alan_dashboard/pages/leading_sector.py`），技術面採 A、E 模型的完整條件，
  創新高改為 480 日**盤中最高價** × 90%。
  儀表板為觀察雷達、本策略為交易系統，兩者分工與領先股概念
  見 `docs/alan_dashboard_leading_sector.md` 的「判讀邏輯」一節
- **選型依據**：AE／AG × 90%／95% 四組回測（Notion「領先潛力族群策略調整回測」），
  AE 90% 的年化 ÷ 最大回檔最佳

## 進場條件

買入訊號 = 籌碼面 AND 基本面 AND 技術面（三大類全部成立）。
籌碼面與基本面依子策略成對綁定（A'：買超前 20＋營益率 +0.1%；E'：買超前 40＋營益率 +12%），兩組擇一成立即可。

### 籌碼面

以「買賣超股數 ÷ 發行股數」計算比例後，在全市場（TSE + OTC）橫向排名。
**外資 ｜ 投信 ｜ 自營商 ｜ 主力（前 15 大券商）四者擇一成立即可**。

| 來源 | 條件 |
| --- | --- |
| 外資（外陸資買賣超，不含外資自營商） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 `top_n` |
| 投信 | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 `top_n` |
| 自營商（自行買賣） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 `top_n` |
| 主力（top15 買 − top15 賣） | 排名前 `top_n` **且** 同時滿足對應比率門檻（見下表） |

主力額外的比率門檻（需與同期間排名條件同時成立）：

| 期間 | 比率門檻 |
| --- | --- |
| 1 日 | > 0.08%（0.0008） |
| 2 日累計 | > 0.15%（0.0015） |
| 3 日累計 | > 0.25%（0.0025） |

本策略的 `top_n` 依子策略不同：A' = 20、E' = 40（見下方參數表）。

### 基本面

| 子策略 | 營業利益率 QoQ 成長門檻 |
| --- | --- |
| A' | 本季營益率 > 前季 × **1.001**（成長 **0.1%** 以上，形同僅要求「不衰退」） |
| E' | 本季營益率 > 前季 × **1.12**（成長 **12%** 以上） |

### 技術面

| 項目 | 條件 |
| --- | --- |
| 均線上升 | MA5、MA10、MA20、MA60 皆較前一日上升 |
| 價格站上均線 | 收盤價同時 > MA5、MA10、MA20、MA60 |
| 乖離率 | 5/10/20/60/120/240 日乖離率**全部**落在各子策略設定區間內 |
| 量能翻倍 | 成交股數 > 前一日成交股數 × 2 |
| 成交量下限 | 成交股數 > 500,000 股（500 張） |
| 股價下限 | 收盤價 > 12 元 |
| 成交金額 | 收盤價 × 成交股數 > 30,000,000（3,000 萬元） |
| DMI（14 日） | **+DI > 24** 且 **−DI < 21** |
| KD（台股式，fastk 9、alpha 1/3） | K 較前一日上升 **且** D 較前一日上升 |
| MACD（12, 26, 9，加權收盤價） | DIF 較前一日上升 |
| 低點乖離上限 | 收盤價 ÷ 近 **15** 日最低價 ≤ **1.32**（收盤不高於近 15 日最低價的 **132%**） |
| 創新高 | 收盤價 ≥ **480** 日**盤中最高價** × **90%**（取 K 線最高點而非收盤新高，與七模型不同） |

**與 A、E 模型的差異**：只有創新高一項。A 原有的「120 日收盤新高 × 100%」與「480 日收盤高 × 85%」、
E 原有的「480 日收盤新高 × 100%」全部拿掉，改為統一的「480 日盤中最高價 × 90%」；
均線、乖離區間、量價、DMI、KD、MACD、低點乖離上限與各模型定義完全相同。

MACD 以**加權收盤價 `(H+L+2C)/4`** 自算（`strategy_class/taiwan_macd.py`），匹配 XQ 等台股看盤軟體；KD 同為台股式自算。

## 出場條件

`sell_type = 'simple'`

```
(3日線下彎 AND DIF 下彎 AND 3日乖離 < -0.5% AND 5日乖離 < -0.5%)
OR (3日乖離 < -3.5% AND 5日乖離 < -3.5%)
```

| 項目 | 判定 |
| --- | --- |
| 3 日線下彎 | MA3 < 前一日 MA3 |
| DIF 下彎 | DIF < 前一日 DIF |
| 3 日乖離 | (收盤價 − MA3) / MA3 < −0.005 |
| 5 日乖離 | (收盤價 − MA5) / MA5 < −0.005 |
| 獨立急殺出場 | 3 日乖離 < −3.5% **AND** 5 日乖離 < −3.5% |

前四項需**同時**成立才出場；「獨立急殺出場」為**獨立 OR 條件**，
3 日與 5 日乖離同時 < −3.5% 時不受「3 日線下彎 AND DIF 下彎」前提限制、直接出場。
持倉以 `hold_until` 方式維持至出場訊號出現。
