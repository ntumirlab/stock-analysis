# ACE（A85% C80% E）簡單出場

- **類別**：`AlanTWStrategyACESimple`
- **檔案**：`strategy_class/alan_tw_strategy_ace_simple.py`
- **子策略**：A、C、E，買入訊號取三者聯集

## 進場條件

買入訊號 = 籌碼面 AND 基本面 AND 技術面（三大類全部成立）；A、C 另加 480 天新高門檻。

### 籌碼面

以「買賣超股數 ÷ 發行股數」計算比例後，在全市場（TSE + OTC）橫向排名。
**外資 ｜ 自營商 ｜ 主力（前 15 大券商）三者擇一成立即可**，投信不計入。

| 來源 | 條件 |
| --- | --- |
| 外資（外陸資買賣超，不含外資自營商） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 `top_n` |
| 自營商（自行買賣） | 1 日 **或** 2 日累計 **或** 3 日累計比例排名前 `top_n` |
| 主力（top15 買 − top15 賣） | 排名前 `top_n` **且** 同時滿足對應比率門檻（見下表） |
| 投信 | **不列入**買進條件 |

主力額外的比率門檻（需與同期間排名條件同時成立）：

| 期間 | 比率門檻 |
| --- | --- |
| 1 日 | > 0.08%（0.0008） |
| 2 日累計 | > 0.15%（0.0015） |
| 3 日累計 | > 0.25%（0.0025） |

本策略的 `top_n` 依子策略不同：A = 20、C = 25、E = 40（見下方參數表）。

### 基本面

| 子策略 | 營業利益率 QoQ 成長門檻 |
| --- | --- |
| A | 本季營益率 > 前季 × **1.001**（成長 **0.1%** 以上，形同僅要求「不衰退」） |
| C | 本季營益率 > 前季 × **1.125**（成長 **12.5%** 以上） |
| E | 本季營益率 > 前季 × **1.125**（成長 **12.5%** 以上） |

### 技術面

| 項目 | 條件 |
| --- | --- |
| 均線上升 | MA5、MA10、MA20、MA60 皆較前一日上升 |
| 價格站上均線 | 收盤價同時 > MA5、MA10、MA20、MA60 |
| 乖離率 | 5/10/20/60/120/240 日乖離率**全部**落在各子策略設定區間內 |
| 量能翻倍 | 成交股數 > 前一日成交股數 × 2 |
| 成交量下限 | 成交股數 > 500,000 股（500 張） |
| 股價下限 | 收盤價 > 12 元 |
| 成交金額 | 收盤價 × 成交股數 > 30,000,000（3,000 萬元） |
| DMI（14 日） | **+DI > 24** 且 **−DI < 21** |
| KD（台股式，fastk 9、alpha 1/3） | K 較前一日上升 **且** D 較前一日上升 |
| MACD（12, 26, 9） | DIF 較前一日上升 |
| 創新高 | 收盤價 ≥ N 日收盤最高價 × **100%**（N 依子策略而定） |
| 額外新高（僅 A、C） | A：收盤價 ≥ **480 天**收盤最高價 × **85%**；C：× **80%** |

## 出場條件

`sell_type = 'simple'`

```
3日線下彎 AND DIF 下彎 AND 3日乖離 < -0.5% AND 5日乖離 < -0.5%
```

| 項目 | 判定 |
| --- | --- |
| 3 日線下彎 | MA3 < 前一日 MA3 |
| DIF 下彎 | DIF < 前一日 DIF |
| 3 日乖離 | (收盤價 − MA3) / MA3 < −0.005 |
| 5 日乖離 | (收盤價 − MA5) / MA5 < −0.005 |

四項需**同時**成立才出場；持倉以 `hold_until` 方式維持至出場訊號出現。
